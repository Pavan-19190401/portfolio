## 🛠️ Tech Stack

* **Framework:** Next.js 16 (App Router, Turbopack)
* **Frontend:** React 19, TypeScript, Tailwind CSS v4
* **Animations & 3D:** GSAP (ScrollTrigger), Three.js, React Three Fiber, Lenis smooth scroll
* **Deployment:** Vercel

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Pavan-19190401/portfolio.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
